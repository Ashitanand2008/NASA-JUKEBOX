EARTH JUKEBOX FRONTEND — NO STREAMLIT

1. Download and extract earth_jukebox_frontend.zip.
2. Open the extracted folder.
3. Double-click index.html. It opens in your browser.

No Python, Streamlit, npm, or installation is needed for this frontend demo.
An internet connection is needed for the remote Earth background image and Google Fonts.
Image upload, preview, demo sound generation, playback and WAV download run in the browser.

IMPORTANT:
The image-to-sound feature is a prototype that maps image brightness to pitch.
It is not calibrated scientific sonification. For scientific output, connect this frontend
to the team's Python backend using an API and use the original numerical Earth dataset,
units and calibration. This frontend does not yet connect to a Python backend.

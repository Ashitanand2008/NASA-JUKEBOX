From information to experience

How it works

A typical Earth sonification workflow has four stages. Each stage helps listeners understand what the sound represents.

01 / SOURCE

Earth data

Start with a NASA visualization or the numerical dataset behind it.

02 / PROCESS

Extract information

Read the dataset and identify the values or patterns that matter.

03 / SONIFY

Map values to sound

Convert values into pitch, volume, rhythm or duration.

04 / EXPERIENCE

Listen accessibly

Provide playback, descriptions and accessible controls.

The purpose behind the sound

About Earth Jukebox

Earth Jukebox is a student project concept that makes Earth science information more accessible through sound.

Accessibility

  • Clear labels for controls
  • Keyboard-friendly navigation
  • Simple sound explanations
  • Replay and download options
  • Do not rely on colour alone

Data and transparency

  • Record dataset name and source
  • Preserve units and time information
  • Explain how values become sound
  • Distinguish demo audio from scientific output
  • Follow source attribution guidance
This is an independent student project concept, not an official NASA application. The current image-to-sound feature is a demonstration only.
